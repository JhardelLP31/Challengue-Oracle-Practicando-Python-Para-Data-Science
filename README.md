# 📊 Challenge Alura Store - Análisis de Datos

Este repositorio contiene la solución al primer desafío de Data Science del programa **ONE (Oracle Next Education)** y **Alura Latam**.

## 🎯 Objetivo del Proyecto
El objetivo es actuar como un Analista de Datos para ayudar al **Sr. Juan** a tomar una decisión estratégica: **¿Qué tienda debe vender para invertir en un nuevo negocio?**

Para ello, analicé 4 bases de datos de tiendas distintas evaluando 5 puntos clave:
1.  Facturación total (Ventas).
2.  Categorías más populares.
3.  Calificación promedio de los clientes.
4.  Productos más y menos vendidos.
5.  Costo promedio de envío.

## 🛠️ Herramientas Utilizadas
* **Python:** Lenguaje principal.
* **Pandas:** Para la manipulación y análisis de los DataFrames.
* **Matplotlib:** Para la visualización de datos.
* **Google Colab / Jupyter Notebook:** Entorno de desarrollo.

## 📈 Conclusión del Análisis
Tras procesar los datos, la recomendación final para el Sr. Juan es **vender la Tienda 4**.

* **Motivo:** Aunque la Tienda 4 tiene costos de envío eficientes, es la sucursal que **menor facturación genera** en comparación con las otras tres. Para obtener capital, es estratégico desprenderse del activo con menor volumen de ventas.
* **Dato Clave:** La diferencia de facturación entre la tienda líder (Tienda 1) y la Tienda 4 es de más de 100 millones.
